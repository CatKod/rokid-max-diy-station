# scripts

- `tools/capture-usbpcap.ps1` — Windows PowerShell helper to start an USBPcap session.
- `tools/dump-hid.py` — Linux/macOS helper to dump HID inputs from the Rokid Max using `hidapi`/`python-hid`.
- `tools/parse-capture.py` — quick & dirty parser for raw USBPcap exports.

> Scripts are **not** committed yet. Each one will land in its own PR with sample output.
